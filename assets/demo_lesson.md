# 课映 Lecast 演示课件

> 本文件用于生成效果预览 GIF 的演示任务，内容为项目自述，可安全公开。

## 第一章 这是什么

课映 Lecast 是一个把 Markdown 课件自动转换成有声教学视频的本地工具。教师只需准备一份 Markdown 文档，系统即可完成从分章到成片的全部工序。

## 第二章 工作流程

整个流水线分六步：上传课件、智能分章、生成幻灯片、撰写讲解稿、合成语音、导出视频。每一步的结果都可以手动编辑并单独重新生成，人工把关与自动生成相结合。

## 第三章 技术特点

后端采用 FastAPI 与 SQLite，前端使用 Jinja2 模板配合 Bootstrap 5，无需 Node.js。幻灯片由大模型生成 HTML 页面，经 Playwright 截图、FFmpeg 合成，最终输出 1080P 的 MP4 教学视频。
